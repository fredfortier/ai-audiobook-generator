02 / PERFORMANCE

Direct the listener's experience

Score the argument before synthesis: clarify, probe, convince, warn, invite, exalt, urge, and resolve. Keep direction out of spoken text.

03 / DELIVERY

Export chaptered M4B

Resume verified audio segments, assemble lossless samples in order, and derive chapter positions from realized audio.

DIRECTED ORAL INTERPRETATION

Give the argument a living voice.

Some writing addresses a listener: it questions, invites, warns, persuades, or exhorts. Expressive narration can make those actions audible while preserving the text and its qualifications.

The director makes an edition-specific rhetorical score. Adaptation prepares faithful speech, Chatterbox renders the accepted performance, and editorial and listening review determine whether the delivery is ready.

Before your first audiobook

Which books can it process?

The supported intake is EPUB or HTML, with English narration using original Chatterbox. The agent resolves edition scope and ambiguous source structure before adaptation.

Does it clone a reference voice?

Chatterbox uses reference-audio conditioning. The bundled Enoch recording is CC BY 4.0; source books and other recordings retain their own rights and terms.

Is this a one-click converter?

The workflow includes editorial decisions, auditions, and listening review. Automated validation establishes structure and content identities; it cannot certify acting or pronunciation.

What is the current release status?

This is a development preview. Strict type checking has a known backlog. See current checks and tracked issues before using it for production.
